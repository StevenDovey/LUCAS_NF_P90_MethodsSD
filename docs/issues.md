# Open questions and issues

## Questions for the original SAS author

### Dead-wood multipliers (resolved)
Both the 1.767 sampling correction and the 1.19 below-ground uplift apply to
both dead pools, standing dead and fallen debris. The original author confirmed
this was the operational choice, made to carry the uncertainty across the dead
pools as the best available treatment at the time. Each pool is therefore
scaled by the product of the two multipliers. Resolved; no further action.

Original questions, retained for the record:

1. Should the 1.767 sampling correction apply to standing dead, which is fully
   counted rather than line-sampled?
2. Should the 1.19 below-ground root uplift apply to fallen logs, which lie
   above ground?
3. Was applying both multipliers to both dead-wood pools intended, or should
   each apply to one pool?

### Coefficient sources (housekeeping)
4. Which published paper and equation gives each stem, branch, foliage, and
   taper coefficient used?
5. What is the source for the 477 default wood density and the species decay
   constants?

## Status

Every formula and coefficient that drives a carbon number reproduces the
operational reference to zero difference. The questions above do not change a
validated result. The multiplier scope is now resolved (both multipliers apply
to both dead pools, confirmed by the original author); the coefficient sources
are a citation tidy-up, the values already matching the reference exactly. The cabbage-tree root:shoot value of 0.437 is confirmed
against the Easdale 2019 monocot group.
